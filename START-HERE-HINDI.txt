WINDOWS STARTUP
1. Extract this folder.
2. Right-click Start-Portfolio.ps1 and choose Run with PowerShell, OR open PowerShell in this folder and run:
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\run_local.ps1
3. On first run, enter a strong private Admin password when prompted. Remember it; it is not stored in this ZIP.
4. Open the public portfolio: http://127.0.0.1:5000
5. Open Admin Login: http://127.0.0.1:5000/login
   Username: saloni
   Password: the password you created at startup.

PRIVACY & HOSTING
- Never upload private school/university marksheets, IDs, date of birth, address, or confidential documents to a public website. The Magadh result PDF is not automatically exposed. Upload only documents you intentionally want public.
- GitHub Pages cannot run this Flask backend or provide server-side private authentication. Keep the GitHub repository for source code if desired, but deploy the Flask app to a Python host (Render, Railway, etc.) with persistent disk/storage and environment variables ADMIN_USERNAME, ADMIN_PASSWORD, SECRET_KEY. Configure HTTPS and persistent storage before using hosted admin uploads.
- The local server binds to 127.0.0.1 only, so it is available on this computer, not your public network.
- Back up portfolio.db and static/uploads regularly.
